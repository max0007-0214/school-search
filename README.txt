校内資料検索 PWA v0.1

重要：ZIPをiPadの「ファイル」アプリで展開してindex.htmlを開くだけでは、ホーム画面から直接起動するPWAとしてインストールできません。HTTPSで静的ファイルを公開する必要があります。

無料での公開例：GitHub Pages（公開リポジトリを使用）。公開するのはこのプログラム5ファイルだけです。校内資料やバックアップは絶対にアップロードしないでください。公開URLは誰でもアクセスできるため、校内の機密情報・個人情報・認証情報をプログラムに書き込まないでください。

1. このフォルダ内のindex.html, app.js, sw.js, manifest.webmanifest, icon.svgをHTTPSの静的ホスティングに配置する。
2. iPadのSafariで公開URLを開く。
3. 共有メニュー → ホーム画面に追加 → 追加。
4. ホーム画面の「校内資料検索」から直接起動する。
5. 初回起動後、アプリ本体はオフライン利用を想定。資料はブラウザーのIndexedDBに保存されます。

注意：iPadのSafari/ホーム画面アプリの保存領域は、削除・サイトデータ消去・容量管理で失われる可能性があります。定期的にバックアップしてください。PWAとSafariの保存領域の扱いはOSバージョンによって異なります。

対応：txt/csv/md/html/json/xml, docx, xlsx, PDFの一部。doc/xlsの本文抽出不可。画像PDFのOCR不可。PDFの日本語抽出は不完全な場合があります。音声認識、AI質問応答、自然言語からの予定自動登録、外部カレンダーへの直接書き込みは未実装です。
