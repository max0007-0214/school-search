校内資料検索 v0.3 PDF文字抽出版（ダークモード）

既存のIndexedDB school-search-local-v1 を維持します。旧版で登録したPDFは本文が失われているため、元のPDFをもう一度選択して登録してください。ファイル名・サイズ・更新日時が同じ場合は既存レコードを上書きします。

PDF.js 3.11.174 をCDNから初回取得します。PDFの内容はアプリのJavaScript処理で解析し、アプリ自身のコードはPDFをサーバーに送信しません。ただし外部配信スクリプトへの依存があるため、機密資料を扱う前に組織の情報セキュリティ規程を確認してください。

画像だけのPDFにはOCRが必要で、本版では未対応です。複雑な日本語レイアウトは抽出順が乱れる場合があります。

公開するのはプログラムの6ファイルのみ。校内資料、バックアップJSON、PDFはGitHubへ絶対にアップロードしないでください。
